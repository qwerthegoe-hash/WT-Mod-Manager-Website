WT MOD MANAGER — ЗАКРЕПЛЕНИЕ НА ПАНЕЛИ ЗАДАЧ

Windows 10 / Windows 11:

1. Нажмите «Запустить WT Mod Manager» на финальной странице установки.
   Либо откройте WT Mod Manager через меню «Пуск».
2. Когда приложение появится на панели задач, нажмите ПРАВОЙ
   кнопкой мыши по его значку.
3. Выберите «Закрепить на панели задач».
4. После этого приложение останется доступно на панели задач.

Если пункта закрепления нет, это может быть ограничение вашей
версии Windows или политика вашего компьютера.

Почему установщик не делает это самостоятельно?
Windows разрешает закрепление на панели задач с согласия пользователя.
Принудительно менять закреплённые значки от имени установщика нельзя.

Ярлык на рабочем столе выбирается отдельно в мастере установки.
При удалении приложения его пользовательские моды и настройки сохраняются.
