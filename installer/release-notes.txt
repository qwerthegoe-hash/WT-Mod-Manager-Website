WT Mod Manager 1.3.0-beta.10 — Что нового

• VirusTotal теперь подключён к защищённому серверу WT Mod Manager.
• Общий API-ключ не вшивается в Windows EXE и хранится в Supabase Vault.
• Не нужно вводить или сохранять API-ключ в настройках приложения.
• После локальной проверки выбранного мода автоматически запрашивается отчёт VirusTotal по SHA-256.
• Файлы не отправляются в VirusTotal — серверу передаётся только хеш.
• Для защиты бесплатного API используются регистрация устройства и лимиты запросов.
• Исправлены и упрощены элементы интерфейса проверки модов.
• Установка остаётся однофайловой, пользовательские настройки и моды сохранены.

Важно: проверка доступна после привязки аккаунта сайта в приложении.
Лимиты бесплатного VirusTotal API сохраняются. Отрицательный отчёт не
гарантирует безопасность, а неизвестный хеш не является одобрением.

WT Mod Manager — независимый некоммерческий фанатский проект.
