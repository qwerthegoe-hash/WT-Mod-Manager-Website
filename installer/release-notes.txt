WT Mod Manager 1.3.0-beta.13 — Mod Suite 2.0

1. WT Conflict Resolver — показывает конфликтующие игровые файлы, позволяет
   оставить исходные, заменить с резервной копией или отменить операцию.
2. WT Install Preview — до подтверждения показывает добавления, замены,
   неизменённые файлы и примерный объём резервной копии.
3. WT Mod Integrity Monitor — локально проверяет SHA-256 файлов, записанных
   в историю установок, не отправляя их на сервер.
4. WT Compatibility Checker — сопоставляет версию игры, введённую игроком,
   с версией по заявлению автора. Совместимость не сертифицируется автоматически.
5. WT Modpacks — экспорт/импорт списка модов в JSON без передачи ZIP и токенов,
   наборы работают только с уже импортированными файлами аккаунта.
6. WT Timeline — локальная история установок и подтверждённых восстановлений.
7. WT Creator Studio — предпросмотр ZIP/метаданных перед отправкой в каталог,
   обязательная серверная проверка и ручная модерация сохранены.
8. WT Scanner Reports 2.0 — отдельные статусы структуры, CRC, ClamAV,
   VirusTotal и модерации без ложного обещания «100% безопасно».
9. WT Diagnostics Pro — дополнительные проверки места, сети, сбоев;
   кнопка создаёт только отсутствующие папки после согласия.
10. Staged Releases — прозрачная политика поэтапного запуска Beta с
    добровольным ранним доступом; стоп-лист выпусков без замены хешей.
11. WT UI 2.0 — поиск по карточкам настроек и адаптивные колонки «Загрузок».
12. WT Offline Mode — явное отключение запросов GitHub, синхронизации
    и VirusTotal; локальные моды продолжают работать.

ВНИМАНИЕ: Beta 13 остаётся тестовой сборкой. Настоящая подпись Authenticode
требует сертификат издателя; Sigstore provenance и SHA-256 не гарантируют
отсутствие угроз или предупреждений SmartScreen.
Личные моды и настройки не удаляются, никаких автоматических
изменений файлов игры без разрешения пользователя нет.
