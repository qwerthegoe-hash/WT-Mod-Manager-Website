WT Mod Manager 1.3.0-beta.8 — Что нового

• Полностью переработана страница «Загрузки»: карточки аккаунта и обновлений.
• Уведомления сайта и приложения объединены без дублирующей вкладки.
• Три основные вкладки: «Мои моды», «Каталог сайта», «Диагностика и безопасность».
• Уменьшено количество лишних кнопок, добавлена прокрутка на маленьких экранах.
• Локальная проверка ZIP модов: пути, типы файлов, CRC и лимиты распаковки.
• Необязательная проверка SHA-256 через VirusTotal Community API по запросу.
• Личный API-ключ хранится зашифрованным через Windows DPAPI; файлы не загружаются.
• Безопасные сообщения об ошибках синхронизации без потери модов.
• Добавлена возможность официального Authenticode-подписания релизов,
  только если разработчик предоставил настоящий сертификат.
• Настройки, пользовательские моды и старые функции сохранены.

Внимание: проверка структуры ZIP и VirusTotal не заменяют полноценный антивирус.
Пока подписывающий сертификат не настроен, SmartScreen может показывать предупреждение.
Программа — независимый фанатский проект, не связанный с Gaijin Entertainment.
