WT Mod Manager 1.3.0-beta.14 — Обновления в приложении и визуальные камуфляжи

НОВОЕ
1. Установленная Windows-версия теперь обновляется из вкладки «Загрузки»:
   одно подтверждение, загрузка с отображением прогресса, проверка SHA-256,
   штатная установка в прежней папке и запуск обновлённого приложения.
2. При обновлении сохраняются моды, настройки, локальные профили,
   существующее расположение программы и выбранный канал Stable/Beta.
   Обычный новый установщик по-прежнему позволяет выбрать папку установки.
3. Новая коллекция локальных камуфляжей по конкретной технике.
   Выбор шаблона, созданного самой игрой, затем готового набора
   (совместимый .blk + текстуры) или картинки для простого узора.
4. Отдельные номерные наборы «WT Mod камуфляж №001», №002 и далее.
   Исходный шаблон техники не заменяется; остаются предпросмотр,
   подтверждение, безопасное сохранение и возможность отката.
5. Отдельные автоматизированные тесты на искусственных игровых папках
   и проверка полного установщика на Windows.

СОХРАНЕНО ИЗ BETA 13
- WT Conflict Resolver, Install Preview, локальная проверка целостности,
  история установок, совместимость, модпаки, Creator Studio, отчёты
  сканирования, диагностика, Offline Mode и настройки интерфейса.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Это тестовая Beta. Новые камуфляжи устанавливаются локально:
  другие игроки, включая участников взвода, автоматически их не видят.
  Сложные текстуры требуют подходящего .blk и не создаются из любой PNG.
- Для отображения в игре может потребоваться обновить список
  пользовательских камуфляжей и выбрать набор вручную.
- Автоматизированные проверки моделируют файлы игры, но не заменяют
  тестирование реального клиента War Thunder на персональном компьютере.
- Обновления загружают полный официальный установщик, а не дельта-патч.
  Установщик не обходит Windows UAC, SmartScreen или антивирус.
- Authenticode подпись требует реального сертификата издателя;
  SHA-256 и GitHub provenance не гарантируют отсутствие предупреждений.
- Личные моды и настройки не удаляются; никаких незапрошенных
  изменений игровых файлов не производится.
