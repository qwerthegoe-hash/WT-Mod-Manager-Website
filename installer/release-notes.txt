WT Mod Manager 1.3.0-beta.12 — Trust & Reliability

• WT Recovery: обнаружение неожиданного завершения после обновления.
• Локальные отчёты об ошибках без сообщений исключений, токенов и личных путей.
• WT Trust Center: SHA-256 локального EXE и проверка Authenticode в Windows.
• Новый раздел Trust Center на сайте с хешами официальных релизов.
• Smart Update проверяет свободное место до скачивания.
• Выбор канала Stable/Beta прямо в окне «Загрузки».
• SBOM компонентов Python в GitHub Releases и Sigstore-аттестации.
• Dependabot для Python и еженедельный аудит уязвимостей pip-audit.
• Проверка опубликованных SHA-256 не переписывает файлы релиза.
• Очередь модов: кэш структурной проверки для идентичных ZIP и защита от
  голодания заявок с приоритетами для администраторов.
• Более понятные диагностические сведения по архивам и антивирусным статусам.
• Моды, настройки и существующие функции сохранены.

Внимание: автоматическое восстановление EXE не производится без согласия
пользователя. Для установленных версий восстановление идёт через Windows
Installer. Кэш ZIP не означает отсутствие вирусов; окончательная публикация
по-прежнему зависит от модерации.

Подпись издателя требует настоящего доверенного сертификата. GitHub
provenance и SHA-256 сами по себе не отменяют предупреждения SmartScreen.
