WT Mod Manager 1.3.0-beta.9 — Что нового

• Установщик теперь копирует единый WTModManager.exe.
• Assets, config, Python/Qt-зависимости и модули включены в EXE; в папке установки
  больше не должно быть отдельной _internal и деревьев DLL/PYD.
• При обновлении старой установленной версии удаляется только служебная _internal.
• Пользовательские настройки, моды и профили сохраняются в %LOCALAPPDATA%/WTModManager.
• Переносимая и устанавливаемая версия теперь используют идентичный EXE.
• Проверку ключа VirusTotal можно запустить в приложении по запросу пользователя.
• Персональный API-ключ сохраняется только локально, защищён Windows DPAPI.

Важно: упаковка в один EXE НЕ равна криптографическому шифрованию.
При запуске PyInstaller распаковывает библиотеки во временный каталог.
Приложение без доверенной цифровой подписи всё ещё может вызывать предупреждение SmartScreen.

WT Mod Manager — независимый фанатский проект, не связанный с Gaijin Entertainment.
