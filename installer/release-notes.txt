WT Mod Manager 1.3.0-beta.11 — Проверяемая сборка

• Подлинность происхождения EXE подтверждается GitHub build provenance (SLSA).
• Установщик и переносимая версия публикуются вместе с SHA256SUMS.txt.
• Добавлен build-info.json с версией, исходным коммитом, сборкой и хешами.
• Перед публикацией повторно проверяются размер, заголовки EXE и SHA-256.
• Отдельно проверяется статус Authenticode: подписанная сборка не может
  содержать частично или некорректно подписанные файлы.
• Укреплена публикация: релизы с существующим тегом не заменяются новыми.
• Обновления и все пользовательские моды/настройки сохранены.
• Раздел проверки модов работает с серверным VirusTotal и очередью ZIP.

Важно: пока владелец проекта не подключит доверенный сертификат издателя,
EXE остаётся неподписанным и Windows SmartScreen может показывать предупреждения.
Цифровая подпись и аттестация GitHub не гарантируют отсутствие вредоносного кода.
