# WT Mod Manager — профили и библиотека модов

Этот файл описывает новый функционал; **не содержит секретов** и не меняет
существующий Community Chat или WT Guardian.

## 1. Что уже находится в GitHub

- `profile.html`, `profile.js`, `profile.css` — баннер, аватарка,
  никнейм, описание, цвет оформления, настройки публичности, вход по email.
- `creator.html`, `creator.js` — публичная страница автора и его одобренные моды.
- `mods.html`, `mods.js`, `mods.css` — каталог, поиск, фильтры, отправка ZIP,
  свои заявки, карточки, скачивание одобренных архивов, админская модерация.
- Главная страница `index.html` и Community содержат ссылки на библиотеку.

## 2. ОБЯЗАТЕЛЬНАЯ настройка Supabase

Открой Supabase Dashboard -> SQL Editor и **последовательно** выполни:

1. `supabase/profile_upgrade.sql`, если его ещё не запускали.
2. `supabase/community_platform_upgrade.sql`.

Проверь таблицы `community_user_profiles` и `wtmm_mods`, а также **приватные**
Storage buckets:

- `community-avatars`
- `community-banners`
- `wtmm-mod-packages`
- `wtmm-mod-previews`

Бакеты должны иметь `public=false`. Не превращай ZIP-бакет в публичный.
SQL добавляет RLS: пользователи могут подавать заявки от своего имени,
а **только существующие администраторы** из `community_admins` могут
одобрять или отклонять моды.

Потребуется включённая анонимная авторизация в Supabase Auth, как и для
существующего чата. Секретные серверные ключи нельзя помещать в JS/HTML.

## 3. Проверка библиотеки

1. Открой `mods.html` как обычный пользователь.
2. Нажми «Загрузить свой мод», заполни форму и выбери ZIP до 20 МБ.
3. После отправки мод должен быть в **«Мои моды»** со статусом
   «Проверка» и отсутствовать в общем каталоге.
4. В том же аккаунте администратора, который включён в
   `community_admins`, открой «На проверке».
5. Сформируй ссылку на архив, **проверь файл вручную** и только после
   этого одобри или отклони.
6. Одобренный мод должен появиться в каталоге. Через кнопку
   «Получить ссылку для скачивания» выдаётся краткосрочная подписанная ссылка.
7. Убедись, что обычный пользователь не видит и не скачивает чужие
   непроверенные заявки.

**Важно:** ZIP-архивы проверяются человеком. Платформа пока не выполняет
автоматическую антивирусную проверку, поиск запрещённых файлов в архиве
или безопасную распаковку. Не запускай полученные файлы без проверки.

## 4. Проверка профилей

1. Открой `profile.html`, задай никнейм и описание, добавь аватарку/баннер,
   выбери цвет и нажми «Сохранить профиль».
2. Чтобы другие игроки могли просматривать страницу `creator.html?id=...`,
   включи «Публичный профиль». **По умолчанию профиль закрыт.**
3. Проверь, что в публичном профиле видны только одобренные моды.
4. Для восстановления на другом устройстве привяжи email, подтверди письмо,
   затем установи пароль. Для превращения анонимного аккаунта в постоянный
   Supabase требует включить **Manual Linking** в Auth.
5. Для корректной работы подтверждений email проверь настройки сайта и
   разрешённые Redirect URLs в Supabase Auth.

**Анонимные пользователи могут потерять прежний ID при удалении данных
браузера.** Не выходи из анонимного аккаунта до подтверждения email.
