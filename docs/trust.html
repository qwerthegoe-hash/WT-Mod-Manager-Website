Проверка происхождения WT Mod Manager

Здесь можно сверить официальный SHA-256 с GitHub Releases и проверить, какие файлы действительно опубликованы. Проверка происхождения не заменяет антивирус и не отменяет SmartScreen.

Целостность

Каждый опубликованный EXE должен иметь SHA-256. Сравнивай хеш скачанного файла с официальным релизом.

Происхождение

Для новых выпусков доступна аттестация GitHub Actions. Она подтверждает источник сборки, но не является подписью Windows.

Подпись издателя

Цифровая подпись Authenticode показывается только при подтверждении. Неподписанный файл не называем подписанным.

Проверить скачанный EXE

В Windows PowerShell получи SHA-256 своего установщика и сравни его с показанным выше.

Get-FileHash .\WTModManager-Setup.exe -Algorithm SHA256

Для независимой проверки GitHub provenance, если опубликована аттестация:

gh attestation verify .\WTModManager-Setup.exe --repo qwerthegoe-hash/WT-Mod-Manager-Website

Для цифровой подписи Windows:

Get-AuthenticodeSignature .\WTModManager-Setup.exe | Format-List Status,SignerCertificate

Не отключай антивирус или SmartScreen для установки. При предупреждении проверь происхождение, контрольную сумму и результаты анализа файла.
