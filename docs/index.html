GOOD TO KNOW

Frequently asked questions

Is WT Mod Manager free?

Yes. Donations are optional.

Is this an official War Thunder product?

No. This is an independent fan-made project.

Where are downloads hosted?

Official Windows EXE and SHA-256 checksum are available through GitHub Releases.

What can WT Mod Manager organize?

The project focuses on custom sights, camouflages, supported sounds and personal preferences in one desktop interface.

How can I contact the developer?

Open the Support Center to report a bug, suggest an improvement or find the available direct contact option.
