# WT Mod Manager — безопасность загрузок и проверка модов

## Что делает Beta 8

В разделе **Загрузки → Диагностика и безопасность** можно проверить локальный ZIP
или отдельный файл пользовательского мода. Программа не запускает и не распаковывает
файлы на диск во время этой проверки. Проверяются структура ZIP, пути, типы файлов,
CRC, ограничения размера и SHA-256. Такая проверка **не является антивирусом**.

На сайте уже настроена отдельная серверная проверка архивов с помощью ClamAV
и карантинной обработки до публикации. Сигнал о проверенной структуре — не
доказательство отсутствия всех возможных угроз.

## VirusTotal Community API (необязательно)

1. Пользователь самостоятельно получает личный ключ на сайте VirusTotal.
2. В панели безопасности вводит ключ и нажимает «Сохранить ключ».
3. Ключ сохраняется **только на компьютере пользователя**, шифруется через Windows
   DPAPI. Ключ не включён в EXE, в GitHub и не отправляется на сервер WT Mod Manager.
4. Выбирает файл, выполняет локальную проверку и при необходимости нажимает
   «Проверить SHA-256 в VirusTotal».
5. Программа запрашивает **уже существующий отчёт по хешу**. Содержимое файлов
   не передаётся в VirusTotal. Если хеш не известен, результат «не найден»,
   а не «файл чистый».

VirusTotal Public API: до 4 запросов в минуту и до 500 запросов в день,
личный ключ, ограничения для коммерческого использования. Условия могут
измениться; бесплатность на неопределённый срок не гарантирована.
[Условия публичного API](https://docs.virustotal.com/reference/public-vs-premium-api).

Если антивирус помечает файл, это может быть ложное срабатывание, но отсутствие
обнаружений не гарантирует безопасность. Не отключайте Microsoft Defender ради установки.

## Почему Windows SmartScreen предупреждает о новом установщике

SmartScreen учитывает цифровую подпись издателя и репутацию конкретного файла.
У новой неподписанной сборки репутация обычно отсутствует. Проверка VirusTotal
не отменяет предупреждение SmartScreen.

Для подписания доступен **необязательный** механизм в GitHub Actions.
Только владелец проекта может предоставить настоящий сертификат Authenticode.
Два GitHub Actions Secrets используются отдельно:
- `WTMM_SIGN_PFX_BASE64`: base64 содержимое настоящего PFX-файла.
- `WTMM_SIGN_PFX_PASSWORD`: пароль от PFX.

Подпись выполняется **только на push в main** после проверки изменений.
DLL подписывается до упаковки PyInstaller, EXE подписываются после упаковки,
сам установщик — после Inno Setup. Каждая подпись проверяется через SignTool.
При отсутствии обоих секретов сборки остаются неподписанными; работающий CI не
означает, что подпись появилась.

**Нельзя гарантировать отсутствие предупреждений даже с действительной подписью**:
SmartScreen должен накопить достаточную репутацию. Самоподписанный сертификат
для публичной установки не помогает. Принудительное отключение SmartScreen,
изменение политик или добавление исключений в антивирус не используются.

[Рекомендации Microsoft](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

## Ложное срабатывание VirusTotal

Если после повторной проверки и расследования файл действительно безопасен,
разработчик может обратиться к производителю антивирусного движка, выдавшего
предупреждение. VirusTotal сам не меняет вердикты других производителей.

[Процедура VirusTotal](https://docs.virustotal.com/docs/false-positive).
