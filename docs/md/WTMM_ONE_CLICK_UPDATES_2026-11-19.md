# WT Mod Manager — обновление установленного приложения в один проход

Дата: 19 ноября 2026. Основа: текущая v1.3.0-beta.13 / main.
Рабочая ветка: `feature/one-click-in-app-updates-20261119`.
Этот документ относится к новому PR, а НЕ к уже опубликованному EXE.

## Цель

После **одной первоначальной установки** пользователь получает будущие версии
не переходя на GitHub, не выбирая папку установки повторно и не скачивая EXE
вручную. Интернет всё равно нужен: обновлённый установщик загружается в
личный системный кэш автоматически после согласия пользователя.

## Поток для установленной версии

1. WT Mod Manager проверяет GitHub Releases по выбранному Stable/Beta каналу.
   Автоматические проверки выключаются настройкой или офлайн-режимом.
2. При наличии более новой версии в существующей вкладке **«Загрузки»**
   показывается кнопка **«Обновить до ...»**.
3. Пользователь ОДИН раз подтверждает скачивание, проверку и обновление
   в той же папке. До подтверждения никакой установщик не запускается.
4. Скачивание происходит в рабочем потоке PySide6 с отображением процента.
   Файл размещается только в `%LOCALAPPDATA%/WTModManager/updates`.
   Проверяются HTTPS, размер, базовый заголовок PE и SHA-256 из метаданных
   официального GitHub Release. Повторное использование кэша — только
   после повторной проверки хеша.
5. Только после успешной проверки запускается `WTModManager-Setup.exe`
   с параметрами `/SILENT /NORESTART /CLOSEAPPLICATIONS`,
   с явной исходной папкой через `/DIR=...` и приватным маркером
   `/WTMMAUTOUPDATE`. Программа штатно закрывается.
6. Существующий Inno Setup обновляет установленный EXE, сохраняя
   запись удаления и старое расположение. `/SILENT` показывает ход
   установки и ошибки; пользовательские запросы Windows/UAC не обходятся.
7. Только установка с `/WTMMAUTOUPDATE` записывает завершение в локальный
   status-файл и запускает `WTModManager.exe --updated` после установки.
   Обычные /SILENT установки, включая CI, не запускают программу тайно.
8. Новое приложение импортирует сообщение об успешном обновлении
   в существующий Inbox. Сохраняются `%LOCALAPPDATA%/WTModManager`
   и созданные пользователем моды; канал обновлений при автообновлении
   не перезаписывается.

В случае ошибки файла, недостатка места или сбоя запуска Setup текущее
приложение не закрывается. Если сбой происходит уже после запуска
Inno Setup, ошибка видна в установщике, и может потребоваться штатное
восстановление/переустановка. Автоматическая полная транзакционная отмена
для установленного приложения пока не реализована.

## Portable версия

У portable-файла остаётся прежний проверяемый безопасный механизм
замены EXE с сохранением старого исполняемого файла для отката. Автоматическая
замена portable не создаёт записи Windows Installer и не требует
вторичной установки в Program Files. Не путать оба режима.

## Изменённые файлы

| Файл | Изменение |
| --- | --- |
| `src/installed_updater.py` | Проверка загрузки и целевого установленного EXE; передача параметров одному установщику без shell |
| `installer/WTModManager.iss` | Обновление в том же каталоге, отдельный тихий режим, сохранение пользовательского канала, авторестарт после успешного завершения |
| `src/update_checker.py` | Проценты проверенного фонового скачивания и повторное использование проверенного кэша |
| `ui/update_ui.py` | Одно подтверждение для installed-версии, отсутствие второго мастера и сигналы прогресса |
| `ui/online_page.py` | Кнопка «Обновить до ...», прогресс и статус результата |
| `src/main.py` | Соединение сигналов обновления с уже существующей вкладкой загрузок |
| `tests/test_installer_integration.py` | Безопасный запуск, нестандартные пути, защита SHA-256, прогресс |
| `tests/test_update_notifications.py` | Одно подтверждение; отсутствие повторного вопроса после скачивания |
| `tests/test_gui_smoke.py` | Работа QProgressBar и состояний UI |
| `.github/workflows/build-windows-exe.yml` | Ранний запуск updater-тестов до упаковки установщика |

## Что ещё понадобится

- На Windows вручную пройти переход Beta 13 → следующий Beta релиз:
  непрерывное скачивание, закрытие процесса, Inno progress, открытие нового
  EXE, отображение статуса и сохранение старых модов/настроек.
- Проверить кастомные пути с пробелами, несколько мониторов и 125/150% DPI.
- Не публиковать неизменённый tag: `v1.3.0-beta.13` — immutable.
  Для реального обновления потребуется новый номер и полностью успешный
  Windows CI с проверенным Setup/portable и `SHA256SUMS.txt`.
- Установить приложение в первый раз через `WTModManager-Setup.exe`.
  Если установлен только portable EXE, обновление выполняется его отдельным
  portable-updater.
- В будущем можно добавить возобновляемую докачку и более экономичные
  дифференциальные патчи, но только при дополнительной проверке целостности.
  Текущий механизм загружает **полный** официальный установщик, просто
  скрывает ручной поиск/скачивание/выбор каталога.

## Безопасность

Нельзя запускать обновление без подтверждения, обходить UAC, SmartScreen
или антивирус, удалять личные данные и запрашивать серверные секреты в EXE.
SHA-256 подтверждает соответствие опубликованному asset и НЕ заменяет
Authenticode подпись издателя. Действительно подписанные релизы требуют
реального доверенного сертификата. Тесты offline не доказывают работу
на всех пользовательских Windows, до релиза нужны CI и ручная проверка.
