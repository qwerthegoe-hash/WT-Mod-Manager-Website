# WT Mod Manager — улучшение существующего сайта и приложения

Дата: 19 ноября 2026. Основа: текущий main / опубликованная v1.3.0-beta.13.
Этот документ — карта задач и текущих изменений, а не обещание опубликованного EXE.

## Цель

Быстрый понятный каталог модов без потери действующих функций
и простой Windows-клиент, который не заставляет пользователя повторять поиск
или скачивать файлы при каждом изменении запроса.

## Реализовано в рабочей ветке (не в релизе)

| Система | Файлы | Изменение |
| --- | --- | --- |
| Сайт | `docs/mods/mods.html`, `mods.css` | Сброс всех фильтров, кнопка повтора после ошибки сети, контекстные состояния пустых вкладок |
| Сайт | `docs/mods/mods.js` | Один серверный запрос после сброса; синхронизация существующих кастомных селектов; сохранён stale-request guard |
| Сайт | `docs/mods/mods-filter-state.mjs` | Pure-функции для состояния фильтров и пустых результатов без сессий и хранения личных данных |
| Сайт | `docs/js/site-language.mjs` | Тексты новых элементов на пяти поддерживаемых языках |
| Приложение | `ui/online_page.py` | Локальный поиск по названию, категории, версии и описанию; очистка запроса и счётчик |
| Тесты | `tools/test-mod-catalog-controls.mjs`, `tools/check-site.mjs` | Offline регрессии сайта включены в CI |
| Тесты | `tests/test_gui_smoke.py` | Проверки поиска и очистки на вымышленных данных, без серверных запросов |

Ограничения: не меняются Supabase RLS, политика модерации, серверные запросы,
загрузка ZIP и существующие ограничения безопасности. Не добавлена автоматическая
установка модов в игру, не создан новый релиз. Нужны GitHub CI и ручная проверка
в пяти языках, мобильном браузере и на Windows с разным DPI.

## Предлагаемый порядок следующих улучшений

### P1. Надёжность и ясность каталога
- Улучшить сообщения об ошибках: сеть / требуется вход / мод недоступен / нет прав,
  не показывая пользователю внутренние технические ошибки и токены.
- Сохранить позицию прокрутки и фильтры при возврате из карточки мода
  без хранения персональных данных на сервере.
- Проверить отклик пагинации на медленном соединении и запрет дублированных карточек.
- Сделать явные подсказки о совместимости мода и версии War Thunder
  без заявления о гарантированной работоспособности.

### P1. Удобство Windows-приложения
- Объединить после проверки независимые PR: #56 (защита настроек) и
  #57 (поиск игры), затем интегрировать изменения нового каталога через PR.
- Добавить унифицированный drag-and-drop импорт в локальную библиотеку
  с проверкой форматов и лимитов; никогда не исполнять содержимое ZIP.
- Показать ход реальной загрузки через desktop bridge и безопасные сообщения
  об ошибках без автоматической перезаписи игровых файлов.
- Дать пользователю явное предпочтение установки игры при нескольких каталогах;
  сохранять локально, не отправлять пути на сервер.

### P2. Дизайн и доступность сайта
- Проверить таб-навигацию, читабельность при 200% zoom и мобильную сетку
  карточек; тестировать клавиатуру/скринридер.
- Улучшить доступные alt-тексты обложек; сохранять права авторов.
- Привести сообщения профилей, сообщества и библиотеки к общей системе уведомлений,
  не смешивать роли пользователей с ролями модераторов.
- Добавить компактные release-notes к каждому проверенному выпуску.

### P2. Надёжность и безопасность
- Проверить действительные Supabase RLS/права, ZIP/AV/moderation end-to-end
  на безопасных тестовых архивах отдельно от production пользователей.
- Оставить server-only секреты, подпись Windows — только настоящим
  сертификатом издателя, не пытаться обходить SmartScreen.
- Зафиксировать редактируемые версии и требования к ручному тестированию.

## Реальные TikTok-демонстрации

1. «Нашёл мод за секунды» — показать реальный поиск по описанию в приложении
   после проверенной новой сборки.
2. «Фильтры без путаницы» — короткий экран каталога, избранное и сброс.
3. «Если интернет подвёл» — показать кнопку повторной загрузки без перезапуска.
4. «Установка с возможностью отменить» — показать существующий Beta 13
   preview, backup и rollback на тестовом пакете.

Показывать только подтверждённые функции, не выдавать PR за уже доступный
релиз и не обещать 100% антивирусную чистоту. Перед съёмкой скрыть личные
данные, ключи, пути пользователя и не использовать чужие материалы без прав.

## Проверки перед объединением

- `node tools/check-site.mjs`, включая `test-mod-catalog-controls.mjs`.
- `python -m unittest discover -s tests -p "test_gui_smoke.py" -v` на Windows.
- `python -m compileall -q src ui tools tests`.
- Полный Windows Installer CI, desktop sync tests, проверка файлов handoff.
- Ручное тестирование реального браузера и Desktop UI.

Ветку и PR записывать в GitHub; новые функции считаются опубликованными
только после успешного merge, сборки и нового тега релиза.
