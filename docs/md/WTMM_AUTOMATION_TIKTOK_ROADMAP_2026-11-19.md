# WT Mod Manager — автоматизация Windows, простой импорт и подготовка TikTok

Дата: 19 ноября 2026. Репозиторий: qwerthegoe-hash/WT-Mod-Manager-Website.
Основа: v1.3.0-beta.13 (`main`, commit `a122abf4`).
Этот файл — план развития. Наличие пункта здесь НЕ означает, что функция уже опубликована.

## Цель

Обычный игрок должен без оплаты и без изучения папок:
1. открыть WT Mod Manager;
2. увидеть, обнаружена ли установленная War Thunder;
3. выбрать готовый поддерживаемый мод или локальный файл;
4. увидеть ясный предпросмотр изменений;
5. подтвердить установку (когда меняются файлы игры);
6. при необходимости безопасно откатить изменения.

Запрещены скрытые изменения игровых файлов, обходы антивирусов, загрузка незнакомых пакетов без проверки, замена бинарников игры и передача пользовательских путей на сервер. Кнопки установки не должны запускать игру или менять её без согласия. Core-импорт должен оставаться бесплатным.

## Подтверждённое на Beta 13

- Определение ЗАПУЩЕННОГО War Thunder: `src/main.py`; это не равно определению расположения игры.
- Предпросмотр конфликтов, backup/rollback: `src/game_mod_installer.py`, `src/mod_suite.py`, `ui/game_install_ui.py`.
- Отдельные страницы картинок, аудиопредпросмотра, камуфляжей: `ui/sights_page.py`, `ui/sounds_page.py`, `ui/media_page.py`, `ui/camouflages_page.py`.
- Сайт и авторизация/синхронизация: `docs/`, `src/desktop_sync.py`, Supabase. Нельзя считать серверную модерацию непрерывно доступной без live проверки.

Ограничения A: произвольные пользовательские диски НЕ сканируются; нестандартную папку можно выбрать вручную. Для нескольких учётных записей или шаблонов не угадываем выбор человека. Путь сохраняем только при явном выборе на будущем этапе, не в клиентской телеметрии.

### Критерии приёмки A

- Steam и дополнительная Steam-библиотека распознаны по `config.blk`.
- Не создавать отсутствующие директории и не запускать игру только ради поиска.
- Если найден единственный путь, пользователь не видит лишний диалог выбора папки; если найдено несколько, выбор остаётся за ним.
- Предпросмотр, согласие, защита от symlink и backup не ослаблены.
- Windows CI / UI smoke / сайт зелёные; ручная проверка на Steam и Gaijin launcher ещё обязательна.

| Файл | Задача |

| `ui/main_window.py` | Компактная зона «Перетащи файл» и подсказки по типам |

Не обещать «любое изображение автоматически превращается в игровой прицел». Не запускать содержимое ZIP, .bin или .pak.

## Этап E — стабильность, каталог, безопасность

- `src/desktop_sync.py`: явный прогресс, восстановление после обрыва и offline-first.
- `docs/mods/mods.js`: понятная карточка мода и статус валидации; server moderation не подменяется цветным значком.
- `supabase/functions/wtmm-mod-scan/`: отдельно проверить настоящий end-to-end сценарий и ограниченные ZIP fixtures без пользовательских модов.
- `tools/release_integrity.py`, `src/update_checker.py`: проверка хешей, происхождения релизов, невозможность тихой замены EXE.
- Реальная Authenticode подпись требует издателя/сертификата, не решается «упаковкой против антивируса».

## Реальная TikTok-кампания: сначала показываем работающее

Формат: 9:16, 15–25 секунд, запись экрана Windows 1080x1920 через вертикальное кадрирование, крупный UI, скрыть пути пользователя, логины, токены и личные файлы. Съёмка на тестовых модах/демоданных. Звуковое сопровождение — собственное или разрешённое платформой.

### Видео 1 — «Никаких поисков папок вручную»
0–3 с: «Устал искать папку War Thunder?»
3–9 с: свежий экран WT Mod Manager и обнаружение папки игры.
9–17 с: показать автоподстановку (ТОЛЬКО после слияния и проверенной сборки этапа A).
17–22 с: «WT Mod Manager. Бесплатно. Разрабатываем открыто».

### Видео 2 — «Установка без страха потерять оригинал»
0–4 с: «Что, если мод не понравился?»
4–11 с: показать реальный Install Preview/Conflict Resolver Beta 13.
11–19 с: показать создание резервной копии и штатный rollback на тестовом пакете.
19–24 с: «Проверяй совместимость. Ссылка на проект — в профиле».

### Видео 3 — «Прицелы, камуфляжи и аудио в одной библиотеке»
0–4 с: вкладки и короткие названия типов.
4–12 с: импорт демонстрационной PNG/аудиозаписи в библиотеку и предпросмотр.
12–20 с: показать различие между предпросмотром и игровым пакетом.
20–24 с: «Предлагай функции в комментариях». Нельзя обещать автоматическую конвертацию PNG/MP3 в игровые файлы.

### Видео 4 — «Собираем удобный бесплатный мод-менеджер»
0–5 с: «Бета 13 уже доступна».
5–15 с: офлайн-режим, модпаки, диагностика (только реальные кнопки).
15–22 с: GitHub Releases/Trust Center без ложных обещаний безопасности.
22–25 с: «Какую функцию добавить следующей?»

### Правила публикаций
- Сначала скачать и вручную проверить конкретную сборку; не снимать несуществующие экраны.
- Не показывать чужие камуфляжи, музыку или игровые ролики без прав.
- Не использовать массовые боты/накрутку, обещания «100% без вирусов» или «Windows никогда не предупреждает».
- Публикации строить вокруг реального улучшения удобства, feedback и changelog.
